Enumeration naming:
	enum EMyEnumeration {
		EMyEnumeration_Value1,
		EMyEnumeration_Value2,
		...
	};

    OR 

    enum class EMyEnumeration {
        Value1,
        Value2,
        ...
    };

Interface classes` names are prefixed with a capital "I".
Regular classes are prefixed with a capital "C". Structures does not have any prefix.

Big prefixes:
	s_*	-	A static variable
	g_*	-	A global variable
			(has a priority over s_*)

    m_* -   A class member. Omitted inside simple data-oriented structs.

	t_*	-	A non-typename template argument
			(like "template <int t_iArg> class ...")

	i_*	-	GLSL interface block
	u_*	-	GLSL uniform variable
	a_*	-	GLSL vertex attributes

Prefixes:
	i	-	Any integer
	f	-	Any floating-point value
	v	-	A geometrical vector
	p	-	Any pointer
	fp	-	A function pointer
	a	-	An "array"
	s	-	A string / char* array
	b	-	A boolean value
	d	-	Any key-value like container

Do not forget to censor all "OS" W*ndows mentions. Be polite.
